# Script — Brush, Brush, Sharky!（5 分钟样片）

定位：**B 儿童向**。1920×1080 / 30fps / 5:00。单场景：蓝色瓷砖牙科诊所。
三个角色固定：鲨鱼 Sharky（病人）、牙齿 Tino 和 Tilly（助手）。

## 叙事公式（5 段，每段同一个循环）

每段 = 4 镜头，同一个句式：
1. **问题**：脏东西的微距特写（颜色出现）
2. **工具**：Tino/Tilly 举起对应工具
3. **动作**：刷/冲/擦，泡沫和脏东西一起飞
4. **结果**：那一排牙变白，Sharky 笑

颜色即进度条：棕 → 橙 → 粉 → 绿 → 纯白。

## 制作约定

- 旁白：macOS `say`（Samantha，rate 145，比成人向更慢），每句独立 wav，按目标秒数对齐
- BGM：不加（参考片也没有明显音床），先出画面验证
- 字幕：句级烧入，白色粗体 + 深色描边，屏幕下 1/4
- 角标：左下角 `Brush, Brush, Sharky!` 常驻
